# 🏨 房型好评生成器

一个本地的酒店好评生成工具。按房型上传图片，自动生成带文字 + 3 张图片、且内容不重复的好评，每条好评自动附带二维码，扫码可查看、保存、跳转平台。

---

## 🚀 快速启动

### 环境要求
需要安装 **Node.js**（版本 14 及以上）。
- 下载地址：https://nodejs.org/
- 安装时保持默认选项即可。

### Windows
双击 **`启动.bat`**，会自动打开浏览器访问 `http://localhost:8080`。

### Mac / Linux
双击 **`启动.command`**（Mac）或运行 `./启动.command`（需先 `chmod +x 启动.command`）。

> 若双击 .command 无法运行，可打开"终端"，cd 到本文件夹后执行 `node server.js`。

---

## 📖 使用说明

1. **上传图片**：点击各房型卡片里的 **+** 或「填示例」上传/填充图片（每个房型独立图库）。
2. **选中房型**：点击房型卡片头部，即可选中。
3. **生成好评**：
   - 单条：点底部「从 XX 房型选3张生成」
   - 批量：点「批量生成」，选择数量（每条用不同3张图、文字不重复）
4. **保存评价库**：生成后点「保存」，好评按房型归类，含文字 + 图片。
5. **扫码分享**：每条好评自带二维码，扫码打开分享页，可一键复制文字、保存图片、跳转美团/抖音/携程。


---

## ⚠️ 关于扫码分享

**本地使用时**：二维码指向 `localhost:8080`，只有本机能访问，手机扫码打不开。

**要让手机/别人扫码**：需将本应用部署到公网服务器，并在 `server.js` 中把地址替换为你的域名，重启后二维码即指向公网地址。

---

## 🖥️ 手动运行

```bash
node server.js
# 浏览器打开 http://localhost:8080/index.html
```
