# 🚀 房型好评生成器 · 公网部署指引

本地运行时，好评二维码指向 `localhost:8080`，**只有你自己电脑能访问**。要让你本人手机、以及客人/同事扫码都能打开好评，需要把应用部署到一台**公网可访问的服务器**。

本文档提供 3 种方案，从"最快"到"最正规"，请按需选择。

---

## 部署前置说明

- 部署用的代码就是你下载的 **`泊歇酒店UI`** 文件夹（内含 `index.html`、`share.html`、`server.js`、`lib/`）。
- `server.js` 已做优化：**会根据访问者的域名自动生成分享链接**。也就是说，部署到任何域名后，好评二维码会自动指向你的域名，无需改代码。
- 需要 **Node.js** 环境。

---

## 方案一：云服务器部署（推荐，最正规）

适合有云服务器（阿里云/腾讯云/华为云/AWS 等）的用户，长期稳定、可绑域名。

### 第 1 步：准备一台服务器
- 购买一台 **Linux 云服务器**（Ubuntu 20.04/22.04 即可，1核1G 都够用）。
- 安全组/防火墙**放行端口**，默认 `8080`（或你自定义）。

### 第 2 步：登录服务器，安装 Node.js
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v   # 应显示 v18.x 以上
```

### 第 3 步：上传应用
在你本地电脑执行（把 IP 换成你的服务器）：
```bash
scp -r 泊歇酒店UI root@你的服务器IP:/var/www/
```

### 第 4 步：启动应用
```bash
cd /var/www/泊歇酒店UI
nohup node server.js > app.log 2>&1 &
```
- 启动后访问 `http://你的服务器IP:8080` 即可使用。
- 推荐用 `pm2` 守护进程（服务器重启后自动拉起）：
```bash
sudo npm install -g pm2
cd /var/www/泊歇酒店UI
pm2 start server.js --name hotel-review
pm2 save
```

### 第 5 步（可选）绑定域名 + HTTPS
用 Nginx 反向代理，把 `你的域名` 转发到 `localhost:8080`：
```nginx
server {
    listen 80;
    server_name 你的域名.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
配置 HTTPS 证书（推荐用免费的 Let's Encrypt / certbot）后，访问 `https://你的域名.com`，二维码也会自动用 HTTPS。

## 方案二：Railway（免费托管，零命令行，最快）

适合没有服务器、想快速上线测试的场景。Railway 提供免费额度，绑定 GitHub 自动部署。

### 第 1 步：上传代码到 GitHub
1. 注册 GitHub，新建一个仓库（如 `hotel-review`）。
2. 把 `泊歇酒店UI` 文件夹内的文件上传到仓库根目录。
3. 仓库根目录需有一个 `package.json`（内容见文末附录），声明启动命令。

### 第 2 步：Railway 部署
1. 打开 https://railway.app ，用 GitHub 账号登录。
2. 点击 **New Project → Deploy from GitHub repo**，选择你的仓库。
3. Railway 自动识别 Node.js 并运行 `npm start`（即 `node server.js`）。
4. 部署完成后，Railway 会给你一个 `https://xxx.up.railway.app` 域名，直接访问即可。

> Railway 免费额度每月约 5 美元用量，个人演示够用；注意免费的公共域名请求有冷却限制，正式商用建议升级。

### 第 3 步：确认域名
Railway 分配的域名是 `https`，二维码会自动生成正确链接，手机扫码即可打开。

## 方案三：本机 + 内网穿透（零服务器，但需电脑常开）

如果你不想买服务器，且电脑能一直开机，可用内网穿透把本机 8080 映射成公网地址。

### 使用 ngrok（推荐，免费）
1. 本地正常启动：`node server.js`（保持运行）。
2. 另开一个终端：
```bash
ngrok http 8080
```
3. ngrok 会输出一个公网地址，如 `https://xxxx.ngrok-free.app`。
4. 手机访问这个地址即可；生成的二维码也会自动指向它。

> 注意：免费 ngrok 每次启动地址会变，之前生成的二维码会失效。适合临时演示。长期使用建议付费固定域名，或用方案一/二。

## 部署后如何确认二维码正常

部署成功后，在应用里生成一条好评，会看到自动二维码。**手机扫码**验证：
1. 手机能打开分享页 → 部署成功；
2. 分享页显示评论文字 + 3 张图片 → 数据接口正常；
3. 分享页能"一键复制 / 保存图片 / 跳转平台" → 功能完整。

若手机打不开，检查：
- 防火墙/安全组是否放行了 `8080` 端口（或你用的端口）；
- 域名 DNS 是否正确解析；
- 是否用了 HTTP 而浏览器强制 HTTPS（方案一建议配好 HTTPS）。

## 📎 附录：Railway 需要的 package.json

放在 `泊歇酒店UI` 文件夹根目录（与 server.js 同级）：

```json
{
  "name": "hotel-review",
  "version": "1.0.0",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  }
}
```

Railway 等平台会自动识别 `npm start` 并执行 `node server.js`。

## 常见问题

**Q：图片上传到服务器会不会很占空间？**
好评分享时图片会被压缩后存到服务器内存（`shares` Map），服务器重启后分享链接会失效（返回"链接无效"）。如需长期保存分享记录，可考虑把 `shares` 持久化到磁盘或数据库。

**Q：`server.js` 用的是什么端口？**
默认 `8080`。可用环境变量覆盖：`PORT=9090 node server.js`。

**Q：需要域名和 HTTPS 吗？**
不是必须。用服务器 IP + 端口就能用；但 HTTPS 更安全、微信/部分 App 内打开更顺畅，强烈建议绑域名并配 HTTPS。
